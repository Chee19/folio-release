First launch

Folio isn’t code-signed during the beta, so your computer asks you to confirm it once.

macOS

  1. Open the .dmg and drag Folio into Applications.
  2. Open Folio. When macOS says it can’t verify the app, choose Done.
  3. Open System Settings, then Privacy & Security, and choose Open Anyway.

You’ll confirm again after each update until Folio is signed.

Comfortable with Terminal? 
xattr -dr com.apple.quarantine /Applications/Folio.app

Run it after installing, then open Folio as usual.

Windows

  1. Run the installer.
  2. If you see “Windows protected your PC”, choose More info, then Run anyway.
  3. Folio opens when the installation finishes.

PCs with Smart App Control switched on block unsigned apps, so Folio can’t run there yet.

Then add your free keys

  • Crypto Get a free Basic API key from CoinMarketCap.
